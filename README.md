# colorise-text
Очень кратко: это превращает любой текст в набор цветов, где каждому символу Юникода соответствует уникальный цвет. Можно генерировать статические изображения (PNG) или записывать анимацию «расцветания» текста (видео).

А теперь чуть подробнее:

# Текст → Цвета: генератор визуализаций и видео для креативного контента
Этот инструмент превращает любой текст в абстрактную цветовую матрицу, где каждый символ Юникода получает свой уникальный оттенок.  
Есть возможность создавать короткие видео, в которых текст «расцветает» посимвольно. Я думаю, это звучит как интересный контент для соц.сетей. Например,"Превратили Пушкина в цветы!". Однако поиграться одному тоже может быть весело)) 

### Что можно делать
- Визуализировать стихи любимых поэтов или вообще любой другой текст (суть проекта)
- Записывать «цветовые портреты» слов или фраз.  
  Одно слово = несколько цветных квадратов. Идеально для коротких мемов.
- Анимировать код, логи, твиты.  
  Хотите показать, как выглядит ваш код в цвете? Запишите видео, где символы «печатаются» радугой. Это не несёт особую смысловую нагрзку, но можно представить весь занятно для наблюдения. 
- Создавать визуальный ряд для музыки.  
  Задайте текст песни и синхронизируйте скорость анимации с битом — получится самодельное музыкальное видео.
- Генерировать обои и фоны для стримов.  
  Получившуюся PNG-картинку можно использовать как абстрактный фон.
- развивать свою креативность (кто я такой, чтобы её ограничивать)) )

Всё работает прямо в браузере, без серверов и установки,но можно скачать код, если нужен офлайн доступ.

## Как эта галиматья работает?

### 1. Преобразование символа в цвет

Каждый символ во входном тексте имеет числовой код (Unicode code point). Именно по нему определяем его цвет.  
Алгоритм построен так, чтобы похожие символы не сливались, а весь спектр использовался равномерно. 

Формула цвета в пространстве:

```js
hue        = (code * 37 + code * 13) % 360;   // оттенок от 0 до 360°
saturation = 70 + (code % 30);                // насыщенность 70–99%
lightness  = 50 + (code % 20);                // светлость 50–69%
```

- **Оттенок** равномерно размазан по кругу: небольшие изменения кода дают совершенно разные цвета.  
- **Насыщенность и светлота** слегка варьируются, чтобы квадраты не были блёклыми, но и не «вырвиглазными».  
- Одинаковые символы всегда получают один и тот же цвет — это даёт узнаваемость повторяющимся буквам (например, все пробелы станут одного оттенка), а ещё теоритически можно расшифровать.

### 2. Создание цветовой сетки (статическая картинка)

Текст укладывается в прямоугольную таблицу. Пользователь задаёт **ширину** — количество символов в строке.  
Высота вычисляется автоматически: `строки = ceil(длина_текста / ширина)`.

Для рисования используется `<canvas>`. Каждый символ — квадрат со стороной **16 пикселей**.  
Размер холста:  
- ширина = `ширина_сетки * 16` пикселей,  
- высота = `количество_строк * 16` пикселей.

При отрисовке проходим по всем символам, для каждого вычисляем его цвет по коду, закрашиваем соответствующий квадратик.

```js
for (let i = 0; i < text.length; i++) {
    const row = Math.floor(i / columns);
    const col = i % columns;
    ctx.fillStyle = charToColor(text[i]);
    ctx.fillRect(col * cellSize, row * cellSize, cellSize, cellSize);
}
```

**Особенность:** холст масштабируется через CSS-свойство `image-rendering: pixelated`, поэтому при увеличении чётко видны квадраты, а не размытые пятна.

### 3. Экспорт в PNG

Используется стандартный метод `canvas.toDataURL('image/png')`.  
Ссылка на картинку создаётся программно, и браузер начинает скачивание.  
Таким образом, вы получаете растровое изображение, которое можно сразу загружать в соцсети или мессенджеры.

### 4. Запись анимации (видео)

Видео генерируется **браузером в реальном времени** без отправки данных на сервер.

#### Как именно это устроено:

1. **Захват кадров с холста**  
   `canvas.captureStream(30)` создаёт видеопоток с частотой 30 кадров в секунду. Всё, что рисуется на холсте, автоматически попадает в этот поток.

2. **Запись потока MediaRecorder**  
   `new MediaRecorder(stream, { mimeType: 'video/webm' })` сохраняет кадры в контейнер WebM (воспроизводится почти везде).  
   При остановке записи готовый файл скачивается.

3. **Анимация «расцветания» текста**  
   Мы не показываем весь текст сразу. Вместо этого с каждым кадром отрисовывается всё больше символов — в соответствии с заданной **скоростью** (символов в секунду).  
   Например, при 20 символах/с и тексте из 100 символов анимация займёт ровно 5 секунд.

   Алгоритм анимации на `requestAnimationFrame`:
   - Вычисляем, сколько времени прошло с начала записи.
   - Определяем, сколько символов нужно уже отобразить: `символов_сейчас = min(общее_количество, скорость * прошедшее_время)`.
   - Закрашиваем только это количество квадратиков (посимвольно, слева направо, сверху вниз).
   - Когда показаны все символы, запись останавливается (с небольшой задержкой в 0,5 секунды, чтобы последний кадр задержался на экране).

4. **Управление записью**  
   Кнопка «Записать видео» запускает процесс, кнопка «Стоп» позволяет прервать его досрочно.  
   Параметр **скорость** (симв./сек) регулирует темп: чем выше значение, тем быстрее «расцветает» текст.

#### Почему видео получается плавным

- Используется привязка к реальному времени (`performance.now()`), а не счётчик кадров. Это гарантирует, что на быстрых и медленных устройствах анимация займёт одно и то же время.
- После окончания записи холст автоматически перерисовывается в полную статичную картинку, чтобы у вас осталась превью.

### 5. Технические особенности

- **Нет зависимостей**: (пока) чистый HTML, CSS, JavaScript.
- **Работает оффлайн**: можно сохранить страницу и пользоваться без интернета.
- **Лёгкая кастомизация**: изменив `cellSize` в коде, можно менять размер квадратов.
- **Цветовая схема**: HSL выбран потому, что легко гарантирует яркие и различимые цвета независимо от количества символов.

- **Пушкин, Есенин, Маяковский в цвете** — классика, которая может, думаю, собирать просмотры.
- **«Угадай фразу по цветам»** — показываете видео без подписи, подписчики пытаются узнать текст.
- **Цветовой дневник** — каждый день визуализируете короткую мысль или цитату.
- **Дуэты** — один человек читает стих, а на экране одновременно «расцветает» текст.
- **Сравнение языков** — одна фраза на русском, английском, китайском даст совершенно разный цветовой узор.
